Tool for displaying chords and scales on a 2D guitar fretboard.
Features:
- Select different scales and modes and display them on a 2D guitar fretboard in a tab style or notes (switchable)
- Select tuning and string amount (4 string to 9 strings, basses and guitars)
- Show chords based on different inputs (note, scale, mode, minor/major etc.) (separate window)
- Functions:
  - Harmonize function: Select scale -> click harmonize -> show all chords in that scale
  - Export function: Export selected scales, chords, etc. in a pretty format (chooseable themes) (pdf, html, etc.)
  - Random Chord/Scale -> Button to randomly display a chord or scale
  - Filtering chords/scales by categories (sad, evil, melanhonic, dissonant, jazzy, etc.)
Tech Stack:
  - Backend: Rust
  - Frontend: Html, css maybe Tauri 2
